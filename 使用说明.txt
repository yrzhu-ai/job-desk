作业看台 1.0.3
===============

在 Windows 上看任意多个 Linux 账号的作业，也可以记下自己要做的事。
有 Slurm 时看队列。没有作业系统时看 top。
主界面有「作业」和「管家」。
作业按账号1、账号2……排列，点一下切换；「全部」同时看所有账号。
简洁模式分成运行中、排队、已完成、报错。列之间的竖条可以用鼠标拖动，改变宽窄。
功能区可以勾选「隐藏完成」或「隐藏报错」。点上面对应的大数字，会重新显示那一类。
双击一条作业可以写备注，点「保存」或直接关闭都会留下。备注文字直接显示在作业名后面。
完整模式是整张表。作业列表和最下面的账号状态之间有一条横条，可以上下拖动，改变账号状态区域的高低。
完整列表里点「top」可以看当前进程，再点一次收起。
每 10 分钟自动刷新，也可以马上手动刷新。

程序通过 SSH 登录后，只执行 squeue、sacct，或在没有作业系统时执行 top。
不提交作业，不取消作业，不改服务器上的文件。


启动
----

双击「启动作业看台.bat」。
打开后先登录。没有用户名时点「注册」。每个用户的作业账号、便利贴和皮肤是分开的。
核对密码时可以关掉窗口，或按 Esc 退出。核对太久会停下来，可以再试一次。
这台电脑上原来已经保存的账号和便利贴，会归到第一个注册的用户。
登录密码和 Linux 密码不是同一个。
本机需要 Python 3。第一次如果没有 paramiko，脚本会用 pip 安装。

窗口没出现时，在这个目录打开命令行运行：

    py -3 app.py

详细错误在：

    %APPDATA%\LinuxJobDesk\crash.log


添加账号
--------

点左上角蓝色的「账号密码」。还没有账号时，作业页中间也有一张卡片，可以直接填。

每个账号填写：

- 显示名（可以空着，会用用户名）
- 主机
- 端口，默认 22
- 用户名
- 密码
- 附加 PATH，可选。squeue 不在默认 PATH 时填写它所在目录，多个目录用英文冒号隔开，不要加空格

保存顺序就是账号1、账号2、账号3。删掉中间一个后，后面的会按新顺序重新编号。
「测试连接」可以先试。改密码时留空再保存，表示不改原来的密码。
这里只从这台电脑的列表里删除账号，不会动 Linux 上的账号。


看作业
------

账号标签下面的数字是：运行 / 排队 / 完成 / 报错。
报错包括失败、超时、节点失败、内存不足、已取消等。
点上面的大数字，会切到完整列表并只看这一类。
搜索可以按作业名、作业号、账号过滤。
「结束作业近 N 天」只影响已经结束的记录，正在排队和正在运行的都会保留。

「立即刷新」或按 F5 马上重查。
不操作的话，每 10 分钟自动查一次。
双击一条作业可以写备注，运行中、排队、已完成、报错都一样。备注文字显示在作业名后面。
右键一条作业，选择「进入命令行」，会登录那个账号，并尽量进入这个作业的工作目录。你在里面输入的命令会在那台机器上执行。
账号标签上也可以右键，选择「进入命令行」。没有作业时也能进入这个账号，停在家目录。
退格可以删除，左右方向键移动光标。按住 Ctrl，滚动鼠标滚轮可以放大或缩小字体。
命令行默认是柔灰底、深灰字，不是纯黑，光标不闪。左下角「配色」可以换成暖纸、豆沙或墨色。目录蓝、程序绿、链接青、压缩包红仍然分得开。
完整列表里，「全部、运行中、排队、已完成、报错」旁边有「top」。点一次显示当前 top，再点一次收起。
右键还可以查看详情、写备注、复制作业号或作业名。任何状态的作业都可以右键选择「不再显示这条」。这只在这台电脑上做个标记，刷新以后也不会再出现，不会去服务器上取消作业。
自动刷新仍然只查询 squeue、sacct 或 top，不会替你提交或取消作业。


完成提醒
--------

某个账号里，原先还在运行或排队的作业跑完时，会弹出提醒。成功和失败都会提醒。
「现在查看」打开那个账号和这条作业。
「稍后处理」先收起来，主界面会出现「稍后 n」，之后再点进去看。
关掉弹窗，等于这些都稍后处理。
第一次运行只记住当前状态，不会把早就完成的作业全部弹出来。


悬浮球
------

点「悬浮球」，或点窗口的最小化，主窗口会收成一个蓝色圆球，颜色接近微软电脑管家。
圆球上只有两行：任务数，和已完成数量。鼠标移上去会看到运行、排队、完成、报错，以及每个账号的数量。
拖动可以挪位置。单击打开主窗口。右键可以刷新或退出。
窗口右上角的关闭仍然是退出程序。


管家
----

点「管家」。最上面一行可以选择：未完成、今日、进行中、本周、本月、本学期。
点「选择日期」会打开月历。点中某一天后，月历收起来，窗口换成那一天。有任务的日期旁边有一个点。
「加到这一天」会在选中的日期上放一张便利贴。
下面的输入框把一段话交给 DeepSeek，整理成可以直接做的任务，并放进任务列表。点「密钥」填写 API Key。没有密钥时，会按句号和顿号先拆成清单。整理时不发送 Linux 密码。
拖便利贴的标题可以移动位置。拖右边改变宽度，拖下边改变高度。
左上角的数字按写下的先后排列，越晚写下的数字越大。调整叠放不会改这个数字。
右键可以上移一层、下移一层、放到最前或放到最后，也可以选状态、改标题、编辑内容，或放进垃圾桶。
双击便利贴是编辑内容。以前写过的每一条都能改。可以加下一步，也可以从某一条加分支。双击标题可以改标题。
每张便利贴里，主步骤用箭头串起来，分支用弯箭头接在下面。每一条前面有对钩，点一下表示这一条做完。标题旁边的对钩表示整张做完。
文字下面有四个小图案：○ 待做，▶ 进行中，✓ 完成，‖ 暂停。点其中一个就换状态，当前的图案会亮起来。点完成以后，这张便利贴离开当前页面，到「档案」里。
文字下面右边有「明天」和「后天」。点一下，这张便利贴就改到那一天，今天的页面里不再显示。选中那一天，或在日历上点有标记的日期，可以再看到。右键里也有同样的两项。
右上角的星号表示紧急程度。点一下从普通到重要（一个星），再到紧急（三个星），再点回到普通。
标题右边可以选择「便利贴」或「列表」。列表点开一行，里面是子任务，对钩在右边。
「本周」会写成这一周的日期，「本月」会写成这个月。从这里新加的任务，日期按今天所在的星期或月份来记。
「档案」里是点成完成的任务。「垃圾桶」里是收起来的任务，可以恢复，也可以彻底删除。
功能区右侧「文字」可以改字体和字号：微软雅黑、宋体、黑体、楷体，字号从小到更大。字号分成两列，窗口可以拉大，不会把后面的选项挡住。
「皮肤」可以换：深夜、海洋、纸页、新绿。纸页用暖色纸面，运行、排队、完成、报错几栏也跟着变浅。
上下、左右拖动的条用当前皮肤的颜色，是平的。
「退出登录」回到登录页。窗口右上角的关闭仍然是退出程序。
「检查更新」会看有没有更新的版本。有的话可以一键换上，程序会关掉再打开。更新清单是一份 https 上的 json，里面写 version、url、notes。地址可以在检查时填写，也会记在这台电脑上。发给同学之前，把同一行地址写进程序目录的 update_url.txt，再重新打包，同学打开就能检查到。

右上角可以选择提醒间隔：15 分钟、30 分钟、1 小时、2 小时，或关闭提醒。
到点会弹出今日、已到期、正在做的事。
「现在去看」打开管家。「稍后提醒」先关掉，到下一个间隔再问。

账号、作业、便利贴这些弹出的窗口，都出现在作业看台窗口的中间。


密码和密钥放在哪
----------------

%APPDATA%\LinuxJobDesk\users.json 里是登录用户。
每个用户的 Linux 账号和便利贴在 %APPDATA%\LinuxJobDesk\users\用户编号\config.json。
Linux 密码用当前 Windows 用户加密。登录密码只留下校验，不明文保存。
项目目录里没有密码。换电脑或换 Windows 用户后，需要重新填写。
