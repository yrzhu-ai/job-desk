# 宠物素材 / Pet art

把图片放在这里，悬浮球就会在「任务完成、任务失败、久置无事」时变成桌面宠物；
没有图片时，它就是一个普通的小数字条（不显示宠物）。

## 放哪里

任选一个位置，程序会按顺序找：

1. `作业看台.exe` 同目录下的 `pet/`
2. `%APPDATA%\LinuxJobDesk\pet\`
3. 源码目录下的 `pet/`

## 目录结构

```
pet/
  pet.json          # 可选
  idle/1.png 2.png 3.png ...     # 待机（必须）
  happy/1.png ...                # 任务完成时（可选）
  sad/1.png ...                  # 任务失败时（可选）
  trick/1.png ...                # 久置表演才艺（可选）
  drag/1.png ...                 # 拖动时（预留，可选）
```

- 每一帧一张 **透明背景 PNG**
- 同一状态的所有帧**尺寸一致**（建议 128×128 或 256×256，程序不会自动放大）
- 帧按文件名数字排序：`1.png, 2.png, ..., 10.png`
- 每个状态建议 2~8 帧；`idle` 可以只有 1 帧（静止图也行）

## pet.json（可选）

```json
{
  "frame_ms": { "idle": 300, "happy": 100, "sad": 140, "trick": 110 },
  "hold_ms":  { "happy": 3000, "sad": 3000, "trick": 5000 }
}
```

- `frame_ms`：每个状态每帧显示多少毫秒（越大越慢）
- `hold_ms`：这个状态总共显示多久，然后自动变回数字条

## 素材从哪来

- **Shimeji 皮肤**：网上大量现成的 Shimeji 角色包，解包后取 `idle` / `walk` 帧即可（注意原作者授权）
- **Codex 宠物图集**：8×9 的动作图集，可以用工具切成单帧
- **自己画 / AI 生成**：画一个角色，分别画「待机、开心、难过、表演」几个姿势，导出透明 PNG
- 参考风格：Shimeji（像素/卡通小人）、Bongo Cat（极简线条）、Codex 图集（表情丰富的小动物）

> 小提示：宠物只在**任务状态变化**或**连续 3 分钟没有变化**时出现几秒，
> 平时始终是数字条，不会挡视线。
